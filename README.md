## Article: How Software Development is Changing Forever

[Article Link](https://dev.to/jdbar/how-software-development-is-changing-forever-and-how-youll-need-to-change-with-it-1jih)

I found this article interesting because it looks at how AI is changing software development without simply arguing that AI will either replace developers or solve everything for them. One idea that stood out to me was the comparison between AI-assisted coding and previous changes in programming, such as the move from assembly language to higher-level languages. The article argues that these changes made programming more abstract and allowed developers to focus on solving larger and more complex problems. It presents AI as another step in this process, where developer can describe what they want instead of writing every part of code.

 The author's perspective on what developers will need to focus on in the future is also interesting. He explains that developers will still need to be good at breaking down problems, understanding user and business needs, designing systems as well as critically evaluating the code that AI produces. Thus, understanding how and why a system should be built is as important as knowing how to implement it. The article emphasizes that adapting to new tools is an important part of being a developer and programming is not only about memorizing syntax.
